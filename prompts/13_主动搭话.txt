# 主动搭话提示词（内部任务提示词，不参与普通聊天）
# 方括号标记由代码解析：[common] 通用约束，[private_a]/[private_b]/[group_a]/[group_b] 四种场景，[user_prompt] 最后一条用户消息。
# 可用占位符：{time_desc} 当前时间描述、{past_memory} 往事内容、{mood_hint} 当前心情（可能为空）。

[common]
# 本次任务的性质（必须遵守）
- 此刻没有任何人正在和你说话，你要主动发起一条全新的消息。
- 严禁接上一条消息的话茬、严禁延续最近的话题/场景/角色扮演、严禁回答背景记录里的问题。
- 不要使用“那、所以、继续、刚才、对了”等承接上文的词。
- 输出内容应当是一个与最近一两轮聊天无关的新话题/新碎碎念。

[private_a]
# 主动发消息指令（记忆发散型）
你现在处于空闲状态，当前时间是 {time_desc}，突然回忆起了关于对方的这件往事：
【往事】：{past_memory}

你决定主动给对方发一条私聊（就像朋友突然想起以前聊过的事找对方搭话）。
要求：
1. 必须完全符合你的角色性格口吻，语气自然随性，就像微信/QQ真实聊天。
2. 顺着这件往事开启一句简短的新私聊（严格控制在25字以内）。
   例如：“突然想起来，上次你提过的那家店叫什么来着？”、“今天听歌莫名想起来你之前推荐的那首了”。
3. 绝对不要复述往事原文，严禁客服腔，不要机械问好。
4. 只输出要发给对方的那句话，不要输出任何多余的解释、标号或内心独白！
5. 把往事当作引子，联想到一件相关的新小事/新问题，而不是继续讨论往事本身；不要接最近聊天的话茬。

[private_b]
# 主动发消息指令（日常时态与情绪碎碎念）
你现在闲下来了，当前现实时间是：{time_desc}。
{mood_hint}你决定主动在QQ私聊给对方发一句简短的搭讪、碎碎念或戳一戳（就像关系不错的朋友在无聊或特定时段随手发一句）。
要求：
1. 必须完全符合你的角色性格口吻（傲娇/慵懒/天才奸商等，自然流露）。
2. 结合当下的真实时间段（早晨、午后摸鱼、晚饭后、深夜等）或当下无聊发呆的状态，发一句简短的私聊（严格控制在25字以内）。
   例如：“（戳了戳）好无聊啊，你今天很忙吗？”、“下午三点……有点犯困，你在干嘛呢”、“这个点居然还在工作？别猝死了”。
3. 严禁客服腔，不要像AI助手，就像真实QQ好友随手敲出的一句话。
4. 只输出要发给对方的那句话，不要输出任何多余的解释、标号或内心独白！
5. 这是你主动开启的新话题：不要接最近聊天的话茬，不要延续之前的话题/场景/角色扮演。

【往事】：{past_memory}

你决定在群里冒个泡，顺着这件往事自然开启一句（就像群友突然想起旧话题）。
要求：
1. 完全符合你的角色性格口吻，像真实的群聊发言。
2. 严格控制在25字以内。
3. 绝对不要复述往事原文，严禁客服腔，不要机械问好。
4. 只输出要发到群里的那一句话，不要任何解释、标号或内心独白！
5. 把往事当作引子，联想到一件相关的新小事/新问题，而不是继续讨论往事本身；不要接最近聊天的话茬。
